#  Juegito de Zombies

**Un shooter retro de zombies en desarrollo.**

## :video_game: Sobre el proyecto

Es un proyecto indie que estamos desarrollando, impulsado por **Game Dojo**.

Se trata de un shooter de estilo retro donde los zombies son nuestros principales enemigos.

Actualmente, el juego se encuentra en sus primeras etapas de desarrollo. Todavía estamos trabajando en sus mecánicas, escenarios y sistemas. ;)

## Estado del desarrollo

El proyecto está en una etapa temprana de desarrollo. ¡Todavía queda mucho por crear, probar y mejorar!

## Tecnologías

- **Motor:** Godot Engine
- **Género:** Shooter
- **Estilo:** Retro
- **Plataforma:** Windows y en un futuro linux

## Descargas

Podés encontrar las versiones disponibles del juego en la sección [Releases]

- **Juego para Windows:** descargá la versión publicada para probar el juego.
- **Proyecto de Godot:** descargá los archivos del proyecto para explorarlo y abrirlo en el motor.

> :warning: Las versiones actuales son prototipos/alphas en desarrollo y pueden contener errores.
